## Learning Path (हिंदी में)

### Phase 1: Python Basics (सप्ताह 1-2)

#### Day 1-2: Variables और Data Types
```python
# Variables बनाना
name = "आपका नाम"
age = 25
height = 5.8
is_student = True
```

#### Day 3-4: Operators और Expressions
- Arithmetic operators (+, -, *, /, %)
- Comparison operators (==, !=, <, >)
- Logical operators (and, or, not)

#### Day 5-7: Control Structures
- if-else statements
- for loops
- while loops

### Phase 2: Data Structures (सप्ताह 3-4)

#### Lists, Tuples, Dictionaries, Sets
```python
# Lists
fruits = ["apple", "banana", "orange"]

# Dictionaries
student = {"name": "राम", "age": 20, "city": "दिल्ली"}
```

### Phase 3: Functions और Modules (सप्ताह 5-6)

#### Functions बनाना
```python
def greet(name):
    return f"नमस्ते {name}!"
```

### Phase 4: Object-Oriented Programming (सप्ताह 7-8)

#### Classes और Objects
```python
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age
```
