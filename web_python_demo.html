🔧 Terminal Access करने के तरीके:

📱 Method 1: Keyboard Shortcut

Ctrl + ` (backtick key)

यह सबसे तेज़ तरीका है!

📱 Method 2: Menu से

Terminal → New Terminal

Top menu में Terminal option ढूंढें

📱 Method 3: Command Palette

Ctrl + Shift + P → "Terminal" type करें

Command palette खुलेगा

📚 Day 1: Variables (Web Demo)

यहाँ Python variables का example है:

# Variables बनाना
name = "राहुल"
age = 25
city = "दिल्ली"
is_student = True

# Print करना
print(f"नाम: {name}")
print(f"उम्र: {age}")
print(f"शहर: {city}")
print(f"छात्र है: {is_student}")
Output:
नाम: राहुल
उम्र: 25
शहर: दिल्ली
छात्र है: True

🔍 Terminal ढूंढने के Tips:

  • Cursor window के bottom में देखें
  • अगर पूरी screen code से भरी है तो View menu check करें
  • कभी-कभी terminal tab में छुप जाता है
  • Right-click करके "Open Terminal" option देखें

🚀 एक बार Terminal मिल जाए तो:

  1. ऊपर दिए गए commands copy करें
  2. Terminal में paste करें (Ctrl+V)
  3. Enter दबाएं
  4. Python program चलेगा! 🎉
