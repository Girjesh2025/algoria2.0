## 📚 Learning Path (12 Weeks)

### Phase 1: Basics (Week 1-2)
- ✅ **Day 1**: Variables और Data Types
- ✅ **Day 2**: Operators
- ⏳ **Day 3**: Control Structures (if-else)
- ⏳ **Day 4**: Loops (for, while)

### Phase 2: Data Structures (Week 3-4)
- ⏳ Lists और Tuples
- ⏳ Dictionaries और Sets
- ⏳ String manipulation

### Phase 3: Functions (Week 5-6)
- ⏳ Function definition
- ⏳ Parameters और return values
- ⏳ Scope और lambda functions

### Phase 4: OOP (Week 7-8)
- ⏳ Classes और Objects
- ⏳ Inheritance
- ⏳ Encapsulation

### Phase 5: File Handling (Week 9-10)
- ⏳ Reading/Writing files
- ⏳ Exception handling
- ⏳ CSV, JSON के साथ काम

### Phase 6: Advanced Topics (Week 11-12)
- ⏳ Libraries (requests, pandas)
- ⏳ Web scraping
- ⏳ GUI applications

## 📖 Learning Tips

### 1. Code Daily
- हर दिन कम से कम 30 minutes code लिखें
- Consistency सबसे important है
- छोटे sessions बेहतर हैं long sessions से

### 2. Practice Projects
- Theory के साथ practical projects बनाएं
- छोटे projects से शुरू करें

## 🔧 Troubleshooting

### Common Issues:

1. **Python not found**
   ```bash
   # Check if Python is installed
   python3 --version
   ```

2. **Module not found**
   ```bash
   # Usually builtin modules, check Python installation
   pip3 install <module_name>
   ```

3. **Permission denied**
   ```bash
   chmod +x script_name.py
   ```
